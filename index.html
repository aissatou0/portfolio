Projet personnel et mémoire de licence · 2026

Sen-E-Docteur

Pour simplifier la prise de rendez-vous médicaux au Sénégal, j’ai interrogé des utilisateurs potentiels, puis développé une plateforme pour les patients, les médecins et les administrateurs.

J’ai relié le front-end React à une API REST Java/Spring Boot et à PostgreSQL pour prendre, consulter et annuler les rendez-vous. J’ai intégré la connexion Google, Cloudinary pour les images et Jitsi Meet pour les téléconsultations, puis déployé l’interface sur Vercel et l’API sur Render. Mon mémoire de licence a obtenu la mention Très Bien.

Projet fil rouge · PST&B Paris · 2026

WorldScope

Une application pour explorer les pays, comparer leurs données géographiques et démographiques et exporter une sélection en JSON.

J’ai développé la recherche, les filtres, le tri et les fiches pays avec React et Redux Toolkit. Une API Node.js/Express interroge REST Countries. J’ai validé six tests avec Vitest, configuré les accès CORS et déployé l’application sur Vercel et Render.

Projet académique · 2026

Assistant documentaire local

Un assistant qui répond aux questions sur des documents PDF et indique les passages utilisés.

En Python, j’ai découpé et indexé les documents dans ChromaDB pour retrouver les extraits pertinents par recherche vectorielle. Ollama génère la réponse localement et Streamlit affiche les sources.
